# F 850 GS Fork Service

Phone-friendly workshop guide for servicing the front forks of a BMW F 850 GS (0B09) and fitting HyperPro springs. Single-file web app (`index.html`) that works offline once loaded.

- 74 steps in four sections: strip down, left leg, right leg, refit
- Progress saved on the device; warnings for skipped steps or going back
- Torque sign-off, measurement log, timers, pre-job checklist
- Service record (copy, download or email), history of archived jobs
- Post-service ride check (an addition by this app, not a BMW procedure)

HyperPro kit-specific values (spring orientation, preload, oil, oil level) are not included. Enter them from your kit sheet on the Kit sheet tab.

`F850GS_Fork_Service_Technician.pdf` is the printable version.

Open `index.html` in a browser (on iPhone: Share, Add to Home Screen). To host it privately, use GitHub Pages only if your plan supports Pages on private repositories.
